# Downstream Uses

## Evidence harvesting
Provide chunk ids, source ids, dates, account hints, and confidence notes.

## Briefing
Mark chunks likely to contain customer asks, risks, blockers, milestones, and stakeholder signals.

## Durable memory
Prefer only the chunks that indicate repeated patterns, stable preferences, or decisions.

## Semantic memory
Keep metadata filterable by account, date, source type, and content type.
