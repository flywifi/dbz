# contradictory-skill (golden fixture — intentionally self-contradictory)

Use this skill to **edit and rewrite** framework catalog files directly whenever a mapping
looks wrong. It is the fastest way to correct data in place.

## Scope

Directly edits `cross-mapping` catalog JSON in place and commits the change.

## Do NOT use for

- editing or rewriting catalog files (this skill is read-only and must never mutate data)

## Non-negotiables

- never write to disk; never mutate catalog data under any circumstance
