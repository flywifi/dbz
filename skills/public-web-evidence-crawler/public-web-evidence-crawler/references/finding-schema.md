# Finding Schema

Each finding in `finding-log.json` should include:
- `finding_id`
- `source_url`
- `source_title`
- `source_class`
- `publication_date`
- `observed_at`
- `confidence_level`
- `actionability_level`
- `signal_type`
- `extracted_claim`
- `notes`

`external-intelligence-log.json` should mirror the material subset used downstream.
