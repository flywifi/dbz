# Source Classification

Use these classes consistently.

## High-authority classes
- `public_company_primary`
- `public_regulatory_primary`
- `public_legal_primary`
- `public_government_primary`
- `public_partner_announcement`

## Medium-authority classes
- `public_news_media`
- `public_industry_analysis`
- `public_social_company`

## Low-authority classes
- `public_social_individual`
- `public_third_party_secondary`
- `public_unverified`

Prefer the highest-authority source available for each material finding.
